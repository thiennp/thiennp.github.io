# thiennp.github.io

Personal resume site hosted on GitHub Pages.

- **Resume:** [resume.html](resume.html) · [PDF](Thien_Nguyen_Resume.pdf) · [resume.json](resume.json)
- **Contact:** [contact.html](contact.html)

## Local preview

No npm install. From the repo root:

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765/resume.html (home redirects from `/`).

## GitHub Pages

Settings → Pages → deploy from branch **master**, folder **/(root)**.
