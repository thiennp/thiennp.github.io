# Work Memory Skill

## Store

`/Users/thien.nguyen/thiennp.github.io/agents/work-memory/`

## Before substantive work

1. Read `INDEX.md`
2. Read `mistakes/INDEX.md`
3. Open only relevant entry files
4. Obey Do/Don’t from matches

## After big enough work

1. Decide if anything is reusable (blocker, mistake, decision, process)
2. Write one entry per `SCHEMA.md`
3. Refresh indexes (`*/INDEX.md`, root `INDEX.md`, `tags/INDEX.md`)
4. Re-check pinned mistakes once

## Commands

- `/work-memory-recall`
- `/work-memory-log`
- `/work-memory-finish-check`

## Do not

- Store secrets
- Paste full transcripts or huge diffs
- Replace project rules or Daily Magic Knowledge Base with this store
