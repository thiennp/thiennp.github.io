# Work memory log

Capture a lesson, mistake, decision, or notable task into cross-project memory.

1. Classify: `mistake` | `lesson` | `decision` | `task`
2. Create `agents/work-memory/<bucket>/YYYY-MM-DD--kebab-slug.md` with frontmatter from `SCHEMA.md`
3. Update that bucket’s `INDEX.md`
4. Update `agents/work-memory/INDEX.md` (Recent + Pinned if high-severity mistake)
5. Update `agents/work-memory/tags/INDEX.md` and `projects/<name>.md` if needed
6. Keep it short: Context → What happened → Do → Don’t — **no secrets**
